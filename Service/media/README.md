# 媒体资源目录

把 MP4 视频放在这里，可以自由创建多级文件夹。封面图片可选；缺少人工封面时，服务会自动截取视频画面。

每个包含视频的文件夹会自动成为首页分类；嵌套目录使用完整相对路径，直接放在本目录的视频归入“未分类”。

```text
动物世界/
├── 01-小猫.mp4
├── 01-小猫.webp
└── 02-小狗.mp4
```

- 视频仅支持 `.mp4`。
- 封面支持 `.webp`、`.png`、`.jpg`、`.jpeg`。
- 视频和封面的扩展名匹配不区分大小写。
- 人工封面必须与视频位于同一目录且基础文件名完全相同，并始终优先使用。
- 缺少人工封面时默认截取视频第 3 秒画面；短视频回退到首帧。
- 自动截帧失败时使用应用默认封面，视频仍会进入列表。
- 自动封面写入独立缓存，不会修改或污染此媒体目录。
- 正式媒体默认不提交到 Git，也不会被打进 Docker 镜像。
