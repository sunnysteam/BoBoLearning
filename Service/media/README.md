# 新增内容收件箱

把新增 MP4 视频放在这里，可以自由创建多级文件夹。封面图片可选；缺少人工封面时，服务会自动截取视频画面。

每个包含视频的文件夹会自动成为首页分类；嵌套目录使用完整相对路径，直接放在本目录的视频归入“未分类”。

```text
动物世界/
├── 01-小猫.mp4
├── 01-小猫.webp
└── 02-小狗.mp4
```

- 视频仅支持 `.mp4`。
- 封面支持 `.webp`、`.png`、`.jpg`、`.jpeg`。
- 视频和封面的扩展名匹配不区分大小写。
- 人工封面必须与视频位于同一目录且基础文件名完全相同，并始终优先使用。
- 缺少人工封面时默认截取视频第 3 秒画面；短视频回退到首帧。
- 自动截帧失败时使用应用默认封面，视频仍会进入列表。
- 服务只会为新放入或同路径重新投放的 MP4 排队转码，不会重复处理已经发布的 HLS 正式资产。
- HLS 分片、封面和 `asset.json` 全部发布成功后，服务会清理对应源 MP4 和同名人工封面；转码失败或资产不完整时保留源文件。
- 正式资产保存在相邻的 `Service/hls-cache`，该目录需要单独备份；本收件箱和正式资产都不会被打进 Docker 镜像。
